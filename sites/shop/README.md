# Fake shop (main eval set + demo stage)

Pages: product list → product detail → cart dialog → checkout form.

Conventions (required for exact scoring and for the demo):
- `original/` has the planted barriers, `fixed/` is the hand-fixed reference (answer key for the fixer), `patched/` is generated by `cli.mjs fix` (gitignored).
- Every planted barrier element (or its container) carries `data-barrier="B<n>"`, and gets an entry in `eval/groundtruth/shop-main.yaml` or `shop-second.yaml` (one file per task flow).
- Plain static HTML/JS, no build step, no external requests (demo must run on localhost with no wifi).
- The demo error must be **deterministic**: the goal gives the card number, and the first payment attempt always fails
  (e.g. the site rejects the first card, the goal lists a backup card). Do not rely on the planner making a typo.
- A trap only matters at task level if it **stops the task**: e.g. a promo/newsletter popup before checkout with no keyboard exit.
  A trap inside the payment dialog doesn't block paying.
- Keep the fixed version's visible text identical to the original (the fixer is forbidden from changing text).

Serve: `npm run serve` → http://localhost:8080/shop/original/

Honesty note: the barriers were planted by a teammate who had read the detector code (hackathon time), so some overfitting is possible.
Barrier list and scripted routes: `eval/groundtruth/shop-*.yaml`, `eval/keys.shop.*.json`; details in `docs/plans/05-fake-shop.md`.
